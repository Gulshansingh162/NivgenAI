API Key Management

Create revocable, role-bound credentials for trusted server-to-server integrations.

API keys are shown only once. Store them in a backend secret manager and send them as X-API-Key. Never put a key in browser code or commit it to source control. Read-only keys can only use GET endpoints; read/write keys can modify data within their owner's role. Portal sign-in continues to use JWTs.
